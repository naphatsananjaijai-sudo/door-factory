📤 วิธีแชร์แดชบอร์ด
เลือกวิธีที่เหมาะกับการใช้งานของคุณ
☁️ ตั้งค่า Google Apps Script (ทำครั้งเดียว ~10 นาที)
  1. ไปที่ script.google.com → กด + New project
  2. ลบ code เดิมออก → วาง Google Apps Script Code จากขั้นตอนด้านล่าง
  3. กด Deploy → New deployment → Type: Web app
  4. Execute as: Me · Who has access: Anyone → Deploy → คัดลอก URL
  5. เปิดไฟล์ .html → หาบรรทัด const GAS_URL = 'YOUR_GAS_URL' → วาง URL
  6. อัปโหลดไฟล์ขึ้น GitHub Pages → กด "อัปโหลดทั้งหมดไป Cloud"
🌐 วิธีที่ 1 — GitHub Pages (ฟรี ถาวร)
1. ไปที่ github.com → สร้าง account → New repository
2. ชื่อ repository: door-factory → Public → Create
3. อัปโหลดไฟล์ index.html (เปลี่ยนชื่อจาก door_factory_v2.html)
4. Settings → Pages → Branch: main → Save
5. ได้ URL: https://ชื่อของคุณ.github.io/door-factory/
✅ ฟรี ตลอดชีพ · ไม่มีโฆษณา · ใช้ได้จากทุกที่ทุกอุปกรณ์
📁 วิธีที่ 2 — แชร์ไฟล์ตรง ๆ
ส่งไฟล์ .html ผ่าน Line / Email / Google Drive
ผู้รับดาวน์โหลดแล้วเปิดด้วยเบราว์เซอร์ได้ทันที
⚠️ ข้อมูลที่บันทึกเพิ่มเติมจะอยู่เฉพาะในเครื่องผู้ใช้แต่ละคน
🔄 การส่งออก/นำเข้าข้อมูล
ข้อมูลที่บันทึกรายวันเก็บใน browser ของแต่ละคน
หากต้องการซิงก์ข้อมูลใหม่ระหว่างเครื่อง ให้กดปุ่ม ส่งออก/นำเข้าข้อมูล ด้านล่าง
☁️ Cloud Sync — อัปโหลดข้อมูลเก่า
หลังจากตั้งค่า Apps Script แล้ว กด Upload เพื่ออัปโหลดข้อมูล 1–23 ก.ค. ทั้งหมดขึ้น Cloud
ทำครั้งเดียวก็พอ (ใช้เวลาประมาณ 1–2 นาที)
